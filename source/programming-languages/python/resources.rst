Online Python Resources
=======================

Below is a list of online resources made by the people of the Internet for learning Python.

1. `The Python Tutorial`_

2. `Automate the Boring Stuff with Python`_
    An online book (also available to purchase as a physical book).

3. `CS50's Introduction to Programming with Python`_
    Video lectures (slides and notes provided) with exercises.

4. `Python Programming MOOC 2026`_ Course
    Text-based lessons with exercises.
