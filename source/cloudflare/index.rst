Cloudflare
==========

Cloudflare provides a range of Internet services, including content delivery network (CDN), services, cloud cybersecurity, DDos mitigation, and ICANN-accredited domain registration. The company's services act primarily as a reverse proxy between website visitors and a customer's hosting provider, improving performance and protecting against malicious traffic.
