Web Development
===============

**Web Development** is the process of building, coding, and maintaining websites and web applications so they run smoothly on the Internet.


Core Layers
+++++++++++

.. grid:: 1
    :gutter: 3

    .. grid-item-card:: Front-End (Client-Side)

        Build what users see and interact with in their web browser. It relies on HTML (structure), CSS (styling and layout), and JavaScript (interactivity), along with frameworks like React.

    .. grid-item-card:: Back-End (Server-Side)

        Manages the server, databases, application logic, and APIs behind the scenes. Common languages and environments include Node.js, Python, PHP, Java, and Ruby.

    .. grid-item-card:: Full-Stack

        Combines both front-end and back-end development responsibilities.
