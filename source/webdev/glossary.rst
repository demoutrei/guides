Glossary
========

.. glossary::

    Back-End
      Manages the server, databases, application logic, and APIs behind the scenes. Common languages and environments include Node.js, Python, PHP, Java, and Ruby.

    Canvas API
      Provides a means for drawing graphics via JavaScript and the HTML ``<canvas>`` element. Among other things, it can be used for animation, game graphics, data visualization, photo manipulation, and real-time video processing.

    Front-End
      Build what users see and interact with in their web browser. It relies on HTML, CSS, and JavaScript, along with frameworks like React.

    Full-Stack
      Combines both front-end and back-end development responsibilities.

    Web Development
      The process of building, coding, and maintaining websites and web applications so they run smoothly on the Internet.
